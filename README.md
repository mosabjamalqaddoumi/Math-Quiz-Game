Math Quiz Game

A console-based Math Quiz Game developed using C++ and Visual Studio.

Features
- Multiple difficulty levels: Easy, Medium, Hard, and Mixed.
- Arithmetic operations: Addition, Subtraction, Multiplication, Division, and Mixed Operations.
- Randomly generated math questions.
- Color-coded feedback for correct and incorrect answers.
- Score tracking and final game results.
- Interactive console interface.

Technologies Used
- C++
- Visual Studio

How to Run
1. Clone or download the repository.
2. Open `MathGame.vcxproj` using Visual Studio.
3. Build and run the project.
